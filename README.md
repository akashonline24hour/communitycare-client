# 🤝 CommunityCare (Hermione Community Events)

> A modern, full-stack platform connecting compassionate citizens with direct local community initiatives, volunteer drives, and social welfare programs.

---

## 🚀 Tech Stack

### **Frontend (`nextjs`)**

- **Framework**: Next.js (App Router, Turbopack)
- **Styling**: Tailwind CSS with custom Teal/Emerald (`#0b3c3d`) and Warm Orange (`#f07b42`) design system
- **Icons & Notifications**: Lucide React, `react-toastify`
- **Authentication Client**: Better-Auth (`auth-client`)

### **Backend (`express`)**

- **Server**: Node.js & Express.js REST API
- **Database**: MongoDB with native MongoDB Node.js Driver (`ObjectId` validation)
- **Authentication**: Better-Auth with MongoDB adapter & Social OAuth (Google, GitHub)

---

## ✨ Key Features

- **🎨 Theme & UI**: Smooth light and dark mode support with persistent state handling via `next-themes`.
- **🔐 Authentication**: Secure email/password registration alongside Google & GitHub social OAuth logins.
- **📅 Event Management**: Create, view, search, and filter community service drives (e.g., relief work, tree plantations, food distributions).
- **🤝 One-Click Participation**: Join or leave initiatives instantly with real-time attendee roster updates.
- **⚡ Production Stability**: Fully optimized for Next.js App Router with robust Suspense boundaries and dynamic route segment handling.
